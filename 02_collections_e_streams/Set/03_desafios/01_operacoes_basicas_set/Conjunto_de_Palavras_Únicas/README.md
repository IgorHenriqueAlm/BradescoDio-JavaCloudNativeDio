# Conjunto de Palavras Únicas

![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)
![Collections](https://img.shields.io/badge/Java%20Collections-Interface%20Set-blue?style=for-the-badge)
![GitHub](https://img.shields.io/badge/GitHub-100000?style=for-the-badge&logo=github&logoColor=white)

Este projeto é um desafio em **Java** com foco no estudo de **Collections**, mais especificamente no uso da **interface `Set`**.  
A proposta é implementar uma classe capaz de armazenar e manipular um conjunto de **palavras únicas**, evitando duplicações automaticamente.

---

## Descrição do Desafio

Crie uma classe chamada **`ConjuntoPalavrasUnicas`** que possui um conjunto de palavras únicas como atributo e implemente os seguintes métodos:

- `adicionarPalavra(String palavra)` → adiciona uma palavra ao conjunto;
- `removerPalavra(String palavra)` → remove uma palavra do conjunto;
- `verificarPalavra(String palavra)` → verifica se uma palavra está presente no conjunto;
- `exibirPalavrasUnicas()` → exibe todas as palavras únicas do conjunto.

---

## Tema Estudado

Este desafio enfatiza o estudo de **Collections no Java**, com destaque para a interface **`Set`**.

### O que foi praticado neste exercício:

- Uso da interface **`Set`**;
- Implementação com **`HashSet`**;
- Armazenamento de elementos **sem repetição**;
- Operações de adição, remoção, busca e exibição;
- Validação de estrutura vazia antes de executar operações.

---

## Aprendizados

Com este desafio, foi possível praticar:

- Conceitos fundamentais de **Collections em Java**;
- Diferença entre armazenar dados em listas e conjuntos;
- Uso da interface **`Set`** para garantir unicidade;
- Implementação com **`HashSet`**;
- Manipulação de dados com métodos como `add`, `remove` e `contains`.
