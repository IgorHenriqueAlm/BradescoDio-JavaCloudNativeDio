Este projeto é um desafio em **Java** com foco no estudo de **Collections Framework**, especialmente no uso da **interface `List`**, da classe **`Collections`** e da ordenação de elementos com base em **`Comparable`**.

---

# Descrição do Desafio

A proposta consiste em criar uma classe chamada **`OrdenacaoNumeros`**, responsável por armazenar números inteiros em uma lista e disponibilizar operações para ordená-los.

Funcionalidades implementadas:

- Adicionar números à lista;
- Ordenar os números em ordem ascendente;
- Ordenar os números em ordem descendente;
- Exibir os valores armazenados.

---

# Tema Estudado

Este desafio enfatiza o estudo de **Collections no Java**, com destaque para:

- **Interface `List`** para armazenamento ordenado de elementos;
- **Classe `ArrayList`** como implementação dinâmica de lista;
- **Classe `Collections`** para ordenação de elementos;
- **Interface `Comparable`**, utilizada internamente na ordenação natural dos elementos do tipo `Integer`.

Esse exercício é importante para compreender como o Java oferece estruturas prontas para manipulação de coleções de dados de forma eficiente e organizada.

---

# Conceitos Praticados

Durante a resolução do desafio, foram praticados os seguintes conceitos:

- Criação e manipulação de listas com `List<Integer>`;
- Uso de `ArrayList`;
- Ordenação de números com `Collections.sort()`;
- Inversão da ordem da lista com `Collections.reverse()`;
- Validação de lista vazia antes da execução de operações;
- Organização do código em métodos com responsabilidade bem definida.

---

# Aprendizados

- Entendimento prático sobre **Collections no Java**;
- Uso da **interface `List`** para manipulação de dados;
- Aplicação da classe **`Collections`** em processos de ordenação;
- Compreensão da ordenação natural de elementos numéricos;
- Reforço na organização de código orientado a objetos.
