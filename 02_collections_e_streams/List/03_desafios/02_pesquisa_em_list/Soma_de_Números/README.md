Este projeto é um desafio em **Java** com foco no estudo de **Collections**, mais especificamente no uso da **interface `List`**.  
A proposta é criar uma classe capaz de armazenar números inteiros em uma lista e realizar operações básicas de manipulação e consulta desses valores.

---

# Tema Estudado

Neste desafio, o principal objetivo é praticar o uso da **Java Collections Framework**, com destaque para a **interface `List`**.

A interface `List` permite:

- Armazenar elementos de forma ordenada;
- Inserir novos valores dinamicamente;
- Percorrer os elementos com facilidade;
- Realizar operações como soma, busca do maior valor e busca do menor valor.

Na resolução, foi utilizada a implementação **`ArrayList`**, uma das mais comuns para trabalhar com listas em Java.

---

## Descrição do Desafio

Criar uma classe chamada **`SomaNumeros`** que possui uma lista de números inteiros como atributo e implementar os seguintes métodos:

- `adicionarNumero(int numero)` → adiciona um número à lista;
- `calcularSoma()` → calcula a soma de todos os números da lista;
- `encontrarMaiorNumero()` → retorna o maior número da lista;
- `encontrarMenorNumero()` → retorna o menor número da lista;
- `exibirNumeros()` → exibe todos os números presentes na lista.

---

# Conceitos Praticados

Durante este desafio, foram trabalhados conceitos importantes como:

---

# Aprendizados

Este desafio ajuda a reforçar:

- O uso prático da **interface `List`**;
- A diferença entre **declarar com interface** e **instanciar com implementação**;
- Como percorrer listas para realizar cálculos e buscas;
- A importância de validar estruturas antes de operar sobre elas.
