
# 💳 Projeto: Conta Banco

Este projeto é parte do desafio do bootcamp **Santander 2025 - Back-End com Java**, promovido pela [Digital Innovation One (DIO)](https://www.dio.me/). A proposta consiste em criar uma simulação simples de abertura de conta bancária utilizando entrada de dados com a linguagem **Java**.

---

## 📋 Descrição do Desafio

A ideia é criar uma classe `ContaTerminal` que solicita ao usuário informações básicas via terminal, como:

- Nome do cliente
- Número da conta
- Número da agência
- Saldo inicial

Em seguida, o sistema exibe uma mensagem formatada confirmando os dados e agradecendo pela criação da conta.

---

## 🎯 Objetivos do projeto

- Praticar a utilização da classe `Scanner` para entrada de dados;
- Exercitar a manipulação de variáveis e tipos primitivos em Java;
- Demonstrar compreensão sobre estrutura básica de uma aplicação Java;
- Aprender a formatar saídas no terminal com `System.out.println`.

---

## 💻 Tecnologias utilizadas

- Java 21
- IDE (VS Code)
- Terminal / Console
- Git e GitHub para versionamento

---

## 🚀 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/IgorHenriqueAlm/conta-banco.git
   ```

2. Acesse a pasta do projeto e compile:
   ```bash
   javac ContaTerminal.java
   ```

3. Execute o programa:
   ```bash
   java ContaTerminal
   ```

4. Siga as instruções no terminal para digitar os dados solicitados.
